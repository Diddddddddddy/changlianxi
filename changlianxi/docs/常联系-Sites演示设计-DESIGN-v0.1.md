## 0. 一页摘要与已确认决策

**一句话**：评委打开公开链接，首屏就是一台可操作的"老人手机"——上下滑动换家人、听声音、点照片发起模拟呼叫，10 秒内动手，2–3 分钟体验完整闭环。

| # | 决策 | 内容 | 理由 |
|---|---|---|---|
| D1 | 演示素材 | 虚构生成照片 + AI 合成预生成音频文件；真人授权录音留作后续可选增强 | 零隐私风险；不依赖评委机器的 TTS |
| D2 | 首屏形态 | 首屏即演示：左侧一句定位 + 右侧可操作手机模拟器，介绍内容后置 | 评委无门槛动手，避免"只看介绍不玩" |
| D3 | 视觉方向 | 全站暖浅色系，无渐变/深色科技风/玻璃拟态；老人端 PRD 色板经对比度核算达标，保留 | 网站气质 = 产品气质；配色不另起体系 |
| D4 | 音频技术 | 全部预生成音频文件（mp3），不用浏览器实时 TTS | 评委浏览器中文语音不可控 |

## 1. 目标与验收标准

### 1.1 目标

- 公开链接免登录可访问；首屏无需"进入演示"按钮即可操作。
- 核心闭环全部可点通：**滑动选人 → 停稳听声音 → 点照片呼叫（模拟）→ 接通/失败/挂断/异常返回**；另有模拟来电接听/拒接。
- 演示全程可辨识为"模拟"，不得让评委误认为真实通话或已接入微信。
- 桌面与手机浏览器均可用；作品帖"怎么用"能按 ≤5 步照着玩起来。

### 1.2 验收清单（上线前逐项勾选）

- [ ] 首屏手机模拟器无需任何前置点击即可看到默认家人大照片
- [ ] 拖动 / 滚轮 / 键盘上下键均可换页，停稳约 300ms 后播放当前人声音
- [ ] 快速连续滑动只播放最终停住页面的声音，不叠音
- [ ] 点照片进入模拟呼叫，"模拟演示"标识常驻；双击不产生两次呼叫
- [ ] 模拟接通页只有照片和红色挂断；挂断回到原联系人
- [ ] 模拟来电可点照片接听、点红色区域拒接，两个区域不共用
- [ ] 模拟无网络 / 无人接听时有语音提示并可返回原照片
- [ ] 首次进入有明确的声音开启引导（浏览器自动播放限制）
- [ ] 手机浏览器（窄屏）下演示可全屏操作，无横向滚动
- [ ] 桌面 Chrome / Edge、Android Chrome、iOS Safari 各完成一轮核心流程（未测项标注）
- [ ] 家属演示页改动刷新后保留（localStorage），并有"仅当前浏览器生效"说明
- [ ] 设计说明页明确写出能力边界（未接微信、无真实通话、素材虚构）

## 2. 设计原则与规范依据

### 2.1 原则（与产品同源）

1. **少即是多**：老人端演示严格复刻 PRD——一屏一人、无常驻设置、无多余按钮。网站外壳同样克制：没有装饰性卡片、没有功能堆砌。
2. **大字醒目**：老人端演示内文字向适老化规范看齐；网站正文也不小于 18px。
3. **配色简洁**：一套暖浅色系贯穿全站，深绿只给主要正向操作，暗红只给挂断/危险。
4. **诚实演示**：所有模拟状态可辨识；能力边界写在明处；不夸大。
5. **声音是内容**：演示的关键体验是"听到家人的声音"，声音引导与播放可靠性优先于视觉花哨。

### 2.2 规范依据（设计数值来源）

| 来源 | 采用的要求 | 用在哪 |
|---|---|---|
| 工信部《移动互联网应用（APP）适老化通用设计规范》 | 无衬线字体；适老版主界面文字 ≥30dp/pt；对比度 ≥4.5:1（字号 >18dp/pt 时 ≥3:1）；禁广告弹窗 | 老人端演示字号、全站对比度 |
| 微信长辈就医适老化设计规范 | 正文 ≥18pt；主要点击区 ≥60×60pt，其他 ≥44×44pt；行距 ≥1.3；颜色不作唯一信息手段；避免复杂手势 | 触控热区、行距、状态表达 |
| WCAG 2.2 | 对比度 AA；可见键盘焦点；尊重减少动态偏好 | 网站可访问性底线 |

> 说明：适老化规范的 dp/pt 与 Web CSS px 在本演示按 1:1 近似映射（手机模拟器按真机逻辑尺寸渲染），属于工程近似，最终 Android 真机以 sp/dp 实测为准。

## 4. 视觉规范（Token 系统）

### 4.1 色彩

沿用 PRD 色板，已核算对比度（相对亮度计算，保留 1 位小数）：

| 角色 | 名称 | 色值 | 用法 | 对比度核算 |
|---|---|---|---|---|
| 页面底色 | 暖纸 | `#F7F7F3` | 全站背景、手机内背景 | — |
| 主文字 | 墨 | `#1B1B1B` | 标题、正文、称呼 | 墨/暖纸 ≈ **16.0:1** |
| 主要正向操作 | 松绿 | `#22754F` | 拨打/接听、主按钮 | 白字/松绿 ≈ **5.7:1**；松绿/暖纸 ≈ 5.3:1 |
| 危险/挂断 | 枣红 | `#B43F3B` | 挂断、拒接 | 白字/枣红 ≈ **5.6:1** |
| 辅助线/边框 | 米灰 | `#E3E1D8` | 手机边框、分隔线 | 仅装饰，不传信息 |
| 次要文字 | 灰墨 | `#5A5A52` | 说明、标注 | 灰墨/暖纸 ≈ **6.4:1** |

补充规则：

- **状态底板**：照片上叠加文字时，用暖纸 92% 不透明底板或墨 72% 不透明底板 + 白字，保证复杂照片背景上文字可读（PRD 要求）。
- **"模拟演示"标识**：松绿之外唯一的强调色使用场景——用墨底白字小牌，不引入第五种彩色。
- 不用渐变、不用彩色光晕、不用深色模式（V1）。
- 颜色永远不作唯一信息手段：状态同时有文字 + 语音。

### 4.2 字体与字阶

**字体族**（系统无衬线，零加载成本，评委机器差异最小）：

```css
font-family: "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", "Source Han Sans SC", sans-serif;
```

不用 Web Font（中文全字库体积不可接受；系统字体在中文 Windows/手机上均可读）。

| 层级 | 大小 / 行高 | 字重 | 用在哪 |
|---|---|---|---|
| 定位语 | 44px / 1.25（移动端 34px） | 700 | 首屏"想你了，就见一面。" |
| 页面标题 | 30px / 1.3 | 700 | 各内容页标题 |
| 老人端·称呼 | 38px / 1.2 | 600 | 手机内家人称呼（≥30dp 规范） |
| 老人端·状态文字 | 28px / 1.3 | 500 | 呼叫/异常状态短句 |
| 网站正文 | 18px / 1.6 | 400 | 介绍、说明 |
| 辅助/标注 | 16px / 1.5 | 400 | "模拟演示"角标、来源注释（不小于 16px） |

规则：正文行长 ≤80 字符；标题不做"单词变色/斜体强调"；不用全大写标签；字重只用 400/500/600/700 四档。

### 4.3 间距、触控与动效

- 间距阶梯：4 / 8 / 16 / 24 / 40 / 64px，组件内聚、区块之间用空白而非分隔卡片。
- 触控：网站按钮热区 ≥44px；老人端演示主操作（整张照片、大拨打按钮、挂断条）远大于 60px，符合主要操作 ≥60pt 规范。
- 可见键盘焦点：2px 松绿外描边，不用默认蓝框也不取消焦点。
- 动效**只响应操作**：换页滑动跟手、状态切换淡入 150ms；无页面加载动画、无自动轮播、无闪烁；`prefers-reduced-motion` 时换页改为瞬切。

### 4.4 手机模拟器外壳

- 逻辑尺寸 **390 × 844 CSS px**（竖屏），桌面端等比完整显示，窄屏占满宽度。
- 细边框（1px 米灰）+ 36px 圆角 + 内部手机状态栏留白（时间/信号仅示意，不仿品牌）。
- 无刘海、无摄像头开孔等装饰；外壳唯一作用是"这是一台手机"。
- 手机外右下/下方是**演示控制台**（见 5.3），与老人界面严格隔离。

### 4.5 去模板化自查（frontend-design 技能要求）

本设计主动规避以下"AI 默认模板"：

- 暖纸底色**不**配陶土色/衬线大标题（那是常见 AI 组合）；我们配松绿 + 系统无衬线，来源是 PRD 的适老定位。
- 不用 01/02/03 编号装饰（除非是真的步骤序列）；不用"A · B · C"中点元信息串；按钮文字不挂"→"。
- 内容不切成统一圆角卡片；阴影最多用于手机外壳一处。
- 首屏的记忆点是**可操作的演示本身**，不是大数字 + 渐变大图。

## 5. 页面详细设计

### 5.1 首页首屏

桌面（≥1024px）：

```text
┌───────────────────────────────────────────────────────────┐
│ 常联系                          家属演示  设计说明  开发记录 │
├───────────────────────────────────────────────────────────┤
│                                                           │
│  想你了，就见一面。                     ┌───────────────┐ │
│                                       │  模拟演示       │ │
│  常联系，帮不识字的长辈                │               │ │
│  自己找到家人、发起视频。              │   家人大照片    │ │
│                                       │               │ │
  ── 演示为模拟互动，素材为虚构人物。     │   [女儿]       │ │
│                                       │               │ │
│  手机上试一试：                        └───────────────┘ │
│  上下滑动换家人，点照片打视频。          演示控制台(5.3)   │
│  [ 开启声音 ]  ← 首次点击激活音频                        │
│                                                           │
├───────────────────────────────────────────────────────────┤
│ 为什么做 / 怎么用 / 能力边界（下方滚动区，见 5.4）          │
└───────────────────────────────────────────────────────────┘
```

- 左列左对齐，定位语 + 两行说明 + 操作引导 + 声音按钮，**没有第二个 CTA**。
- 手机默认显示第一位（默认联系人）家人照片；进入页面**不自动播放声音**，首次点"开启声音"或首次与手机交互后启用（浏览器策略，见 §8）。
- "模拟演示"角标常驻手机顶部状态区，全程不消失。

窄屏（<1024px）：定位语压缩为一行 34px + 一行说明，手机模拟器紧随其下全宽显示；控制台折叠为手机下方一行小按钮；介绍内容最后。

### 5.2 老人端演示（手机内状态机）

与 SPEC 的 `CallPhase` 对应，网页版是同一契约的简化实现：

```text
E01 选人页（默认）
  ├─ 滑动/滚轮/键盘 → E01（另一位家人）
  ├─ 停稳 300ms → 播当前家人声音（单实例，见 5.2.2）
  ├─ 点照片 → E02（锁定 contactId，停止声音）
  └─ 演示控制台"模拟来电" → E04
E02 呼叫中（模拟）
  ├─ 显示"正在帮你给小芳打电话" + 语音；照片保留，"模拟演示"常驻
  ├─ 默认 2.5s 后 → E03 模拟接通（控制台可改为"无人接听/无网络"）
  └─ 唯一操作：取消 → 回 E01
E03 模拟视频中
  ├─ 大字"模拟视频中"，仅底部红色挂断条
  └─ 挂断 → 语音"电话挂断了" → 回 E01（原联系人）
E04 模拟来电
  ├─ 来电家人照片 + 语音"小芳给你打视频电话啦，点一下照片接听"
  ├─ 点照片 → E03；点红色拒接条 → 回 E01
E05 异常（无网络/无人接听/未设置好）
  ├─ 保留原照片 + 对应语音 + 简短文字
  └─ "再试一次"与"返回照片"，不自动重拨
```

硬规则（与 PRD/SPEC 一致，测试锚点）：

1. 一屏一人；网页演示 2–5 位到边界橡皮筋停住（保留演示手感），Android App 已改**循环衔接**（末位下滑回首位、首位上滑回末位）；1 人时滑动无效但不报错。
2. 换页动画进行中禁止点击拨号；拖动抬起不触发点击。
3. 呼叫发起即锁定 `contactId`，双击/快速连点只产生一次请求。
4. 任何异常回到原联系人；不显示"已接通"除非处于明确标注的模拟接通态。

**5.2.1 手势映射**（演示站特有，非老人端新增功能）：

| 评委操作 | 映射 |
|---|---|
| 手机上垂直拖动 | 换页（跟手，松开吸附） |
| 鼠标滚轮悬停手机上 | 换页（节流，一次滚轮事件序列只换一页） |
| 键盘 ↑/↓（手机获得焦点时） | 换页；Enter = 点照片 |
| 窄屏触摸滑动 | 同拖动 |

**5.2.2 声音策略**：

- 单一 `Audio` 实例 + 播放 token：换页/呼叫/来电时旧 token 作废，杜绝叠音与"旧声音放到新照片"。
- 停稳 300ms 才播；每次停稳只播一次；页面隐藏（`visibilitychange`）立即停播。
- 声音未开启时，手机底部出现一次性的轻提示"点这里开启声音"，不反复打扰。

### 5.3 演示控制台（手机外，评委工具）

位置：桌面在手机右侧下方，窄屏折叠为手机下方一条。样式明显区别于老人界面（小字、米灰边框），标题"演示控制（非老人界面）"。

| 控件 | 作用 |
|---|---|
| 模拟来电 | 触发 E04（随机或当前联系人） |
| 呼叫结果：接通 / 无人接听 / 无网络 | 决定下次 E02 的走向，默认接通 |
| 拨打模式：点照片 / 大按钮 | 切换 E01 的拨打入口（大按钮模式下照片不响应拨打） |
| 重置演示 | 清空 localStorage 与状态，回初始 |

### 5.4 首页下方内容区（文案草案）

- **为什么做**：三句场景白描——"妈会刷短视频，却找不到微信里的我。""她想我了，只能等我打过去。""她不识字，但她认得我们的脸，听得出我们的声音。"
- **怎么用（评委 3 步）**：1）开启声音；2）上下滑动，找到"女儿"；3）点照片，体验一次模拟视频呼叫。末尾一句"再试试演示控制里的模拟来电和无网络"。
- **能力边界**：本页为交互演示，未接入微信、无真实通话；人物照片与声音为虚构演示素材；Android 真机验证进度见开发记录。

### 5.5 家属配置演示（V2，`/family.html`）

- 定位：让评委理解"家属做设置，老人零配置"。页面左侧是配置表单，右侧实时预览同一台手机组件（与老人端同一实现，避免两套设计）。
- 可编辑最小集：称呼、排序（上移/下移按钮）、默认联系人、拨打模式；照片与声音从**预置虚构素材库**选择（不提供上传，避免真实隐私素材进入公开站点）。
- 改动写 localStorage，首页演示立即使用新配置；标注"演示配置仅保存在当前浏览器，不代表跨设备同步"。
- PIN、首次引导等流程在设计说明页用静态图呈现，V2 不做完整 PIN 流程。

## 7. 响应式与浏览器限制

- 断点：≥1024px 左右双列；<1024px 单列手机优先；<380px 手机模拟器按宽度等比缩放，保证热区不缩水到 44px 以下。
- **自动播放限制**：所有音频播放必须由用户手势激活；首屏"开启声音"按钮 + 首次手机交互兜底；不把该限制写成产品缺陷（SPEC §9.3）。
- 音频格式统一 mp3（Safari/Chrome 均支持）；不依赖 Web Audio 高级特性。
- localStorage 仅用于演示配置；隐私模式不可用时演示回退为内存态并提示"刷新将重置"。
- 无网络请求依赖（除静态资源本身）：演示逻辑全部本地，托管为纯静态。
