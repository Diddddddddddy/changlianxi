# 常联系 · 视频通话方案调研 v0.1

日期：2026-11-11 ｜ 状态：**已决策（D-Call，2026-11-11 用户确认）**
范围：老人端"点照片 → 真实视频通话"的通话网关选型。不局限于老人场景，覆盖微信唤起、无障碍自动化、微信官方硬件 VoIP、自建 RTC、厂商/运营商通道。

> **D-Call 决策**：① ~~先验证官方小组件（路线 E）~~ → **2026-11-11 模拟器实测证伪（§8），E 排除**；② **主路线 = B 半自动引导（默认）+ A 无障碍自动（家属显式开启的可选增强，失败自动降级 B）**（用户确认）；③ 本届比赛目标 = 11.30 前红米真机打通一路真实视频呼叫（Sites 演示 + 真机证据进作品帖）。

---

## 0. 结论摘要

- **微信没有任何公开 API 能让第三方 App 直接发起微信视频通话**（OpenSDK 只有登录/分享/支付/跳小程序/客服；`weixin://` 只能打开微信首页）。
- 现实可行的路线只有四条：**A 无障碍自动操作微信**、**B 半自动引导（打开聊天+大字语音箭头）**、**C 微信官方硬件 VoIP（WMPF/TWeCall）**、**D 自建 RTC（Agora/TRTC/WebRTC）**。另有一条零风险辅助路径 **E 微信关怀模式原生一键视频（小组件）**。
- **C 本届比赛不可行**（需非个人主体小程序+微信认证+设备类目审核，19 天来不及），写入产品远景。
- **A 体验最好但合规/风控风险真实存在**（2025–2026 微信持续升级自动化打击，详见 §2）。
- **推荐：分层通话网关**——模拟（演示兜底）→ B 半自动引导（默认，零风控）→ A 无障碍自动（家属显式开启的增强，失败自动降级 B）；E 在红米真机上验证后作为官方路径补充；D 作为 P1 远景。

## 1. 微信官方能力边界（已核实）

| 能力 | 能否发起微信视频 | 说明 |
|---|---|---|
| 微信 OpenSDK（移动应用） | ❌ | 仅 登录/分享/支付/拉起小程序/微信客服。无通话接口 |
| URL Scheme `weixin://` | ❌ | 只能打开微信主界面；无公开的联系人类/视频类 scheme，非官方 scheme 随时失效 |
| 小程序 `wx.join1v1Chat` / `setEnable1v1Chat` | ⚠️ 名义上可以 | 微信原生通话 UI、免费；但**双方必须同在一个小程序内且被叫小程序正在运行**，需双方 openid；iOS 兼容性历史口碑差。无法触达"微信聊天里的家人" |
| 小程序硬件 VoIP（WMPF，`wxf830863afde621eb` 插件） | ✅ 设备→微信用户 | 官方"强提醒"：微信用户**不打开微信也能收到来电弹窗**，点进小程序接听。官方目标场景明确包含**智慧养老**。门槛：非个人主体小程序+微信认证+「工具-设备管理」类目+设备审核拿 model_id+设备端跑 WMPF（安卓≥6.0）或 Linux SDK |
| 腾讯云 TWeCall（物联网开发平台） | ✅ 同上产品化 | 设备一键呼叫→微信「服务通知」强提醒→小程序接听。同样需要企业小程序+model_id 审核 |
| 微信关怀模式「一键视频通话」 | ✅ 微信原生 | 关怀模式→视频通话→添加 1–5 位联系人→锁屏/桌面小组件点头像直拨。**iOS 完善；安卓依厂商与微信版本**（有资料称仅 Pixel/部分华为支持锁屏路径，桌面快捷方式不能直拨）。2026 年另有微信 AI 助手语音唤醒"小助，给妈妈打视频" |
| 企业微信↔个人微信 | ❌ 未开放 | 互通仅限消息，未见音视频开放能力 |

**关键判断**：想让家属"留在微信里、零安装"接到电话，官方路径只有硬件 VoIP（C），而它要企业主体与审核；个人/学生团队本届只能用 A/B/E 触达微信。

## 2. 无障碍自动化路线（A）与风控现状

**原理**：AccessibilityService 读屏+模拟点击：打开微信 → 按备注名找到联系人 → 进聊天 → 点「+」→ 点「视频通话」→ 选视频。市面已有同类产品（"老人桌面"等：大头像卡片+一键微信视频+自动接听+远程辅助，按微信备注名定位联系人），证明技术路径成立。

**风险（2025–2026 显著升级，必须如实告知）**：
- 《微信个人账号使用规范》明确禁止"非腾讯开发或授权的第三方软件、插件、外挂"及"未经授权的自动化操作"；2026 年 1 月治理公告把"模拟按键、自动化脚本操控微信"列为重点打击对象。
- **设备特征检测**：豆包 AI 手机案例（2025.12）——微信对具备读屏/模拟点击能力的设备直接报"环境异常"、弹人机验证，**能力存在本身即可能触发**，不限于行为。
- **行为时序检测**：有实测（Appium，微信 8.0.50+，3 台真机）平均 17 分钟触发"操作过于频繁"，第 3 次封禁辅助设备登录权限。
- **脆弱性**：微信 UI 改版即失效；关怀模式/普通模式布局不同；需家属代开无障碍权限（系统级敏感权限）。

**风险分级（我们的场景 vs 黑产）**：营销外挂是批量、高频、持续、多账号；我们是**单次、人工触发、一天几次、单账号、公益目的**。行为特征风险低，但设备特征风险与条款风险仍在，且无法获得腾讯授权背书。**比赛"技术向善"赛道下，全自动操控微信存在叙事争议，评委可能质疑合规性。**

**结论**：A 可做，但必须 ① 默认关闭、家属显式开启并签署风险告知 ② 单次人工触发、拟人节奏 ③ 失败自动降级到 B ④ 文档与演示中如实标注风险。不建议作为唯一主路线。

## 3. 半自动引导路线（B，零风控）

点照片 → App 直接打开微信对应聊天窗口（无障碍只做"打开聊天"一步；或退化到 `weixin://` 开首页）→ 全屏大字+语音+箭头引导老人自己点「+ → 视频通话」。关怀模式下「+」放大、视频通话置顶，引导成本更低。
- 优点：无自动化风控（人是操作者）、无封号叙事问题、工作量小、失败可语音兜底。
- 缺点：老人仍需 2 次点击；不是"一键"。
- 定位：**默认主路线/兜底**，与 PRD"失败关闭、不假装成功"原则一致。

## 4. 自建 RTC 路线（D）

| 方案 | 成本 | 离线触达家属 | 工作量 |
|---|---|---|---|
| 腾讯 TUICallKit（TRTC） | 7 天试用+按量；含 UI 组件，Android/iOS/Web/小程序互通 | 家属装 App 走厂商推送（TIMPush）；小程序端需**企业主体**（live-pusher 限制） | 中（含 UI 组件 1–3 天跑通，双端+账号体系另计） |
| 声网 Agora | **每月 1 万分钟免费**（超出视频 HD 28 元/千分钟），比赛与公益小规模够用 | 同上，需家属装 App + 厂商推送 | 中 |
| 即构 ZEGO 等 | 同类，有试用额度 | 同上 | 中 |
| 纯 WebRTC 自建 | 软件免费；信令服务器自搭；TURN 可用 **Cloudflare Realtime 免费 1000GB/月**（国内质量一般）或 coturn 自建（VPS+带宽） | 最难：家属开网页链接，无推送 | 大（信令+双端+NAT 穿透+推送全自研） |

**共同短板**：家属必须装我们的 App 或打开链接/小程序——**违背"家属留在微信、零安装"的核心前提**；老人端 UI 完全可控（大按钮接听）是优点。19 天双轨并行下做双端真实通话风险高。**定位 P1 远景**（家属端 App/小程序 + 厂商推送），本届不做。

## 5. 厂商/运营商通道（已排除）

- 华为畅连：仅华为设备生态，无第三方发起通话 API（只有投屏 DMP 类接口）。
- 小米/OPPO/vivo：无对第三方开放的视频通话发起能力。
- 运营商 VoLTE/ViLTE 视频通话：需双方同运营商+开通视频业务，国内基本不可用；`EXTRA_START_CALL_WITH_VIDEO_STATE` 依赖运营商支持，排除。

## 6. 方案对比与推荐

| 路线 | 老人操作 | 家属零安装 | 合规/风控 | 工作量 | 本届可行性 |
|---|---|---|---|---|---|
| A 无障碍全自动 | 点 1 下 | ✅ 微信原生来电 | ⚠️ 条款+设备特征风险 | 中 | 可行（增强项） |
| B 半自动引导 | 点 3 下（有语音箭头） | ✅ | ✅ 无 | 小 | **默认主路线** |
| C 官方硬件 VoIP | 点 1 下 | ✅ 微信强提醒 | ✅ 官方 | 大+企业审核 | ❌ 本届不可行→远景 |
| D 自建 RTC | 点 1 下 | ❌ 装 App/开链接 | ✅ | 大 | ⚠️ 风险高→P1 |
| E 关怀模式小组件 | 点 1 下（微信原生） | ✅ | ✅ 官方 | 小（若可用） | 待真机验证 |

**推荐架构（分层 CallGateway，与 SPEC 的网关抽象一致）**：
1. `DemoCallGateway`：模拟通话（已完成，Sites/无微信环境兜底）。
2. `GuidedWeChatGateway`（B，默认）：打开微信聊天 + 全屏语音箭头引导。
3. `AutoWeChatGateway`（A，可选增强）：家属显式开启+风险告知；拟人节奏；任何一步失败立即降级 B 并语音说明。
4. `WidgetGateway`（E，待验证）：若红米真机确认微信暴露视频通话 AppWidget，评估 Launcher+AppWidgetHost 内嵌官方小组件（零风控一键）。
5. 远景：C（官方硬件 VoIP，需企业主体）与 D（家属端 App）。

**真机验证清单（红米 Turbo，插 USB 后）**：
- 微信版本 / 关怀模式入口与「一键视频通话」是否存在；
- ~~`AppWidgetManager.getInstalledProviders()` 查 `com.tencent.mm` 是否暴露视频通话 widget~~（模拟器已证伪，见 §8）；
- 锁屏/桌面小组件直拨是否可用（HyperOS 限制）；
- 无障碍服务在 HyperOS 上的开启路径与存活情况；
- 关怀模式下聊天页「+→视频通话」的实际布局（B/A 的适配基准）。

## 8. 实测验证记录（2026-11-11，模拟器 Android 16 + 微信 8.0.80 arm64 官方 APK）

**结论：路线 E（内嵌微信官方视频小组件）在安卓不可行。**

| 检查项 | 方法 | 结果 |
|---|---|---|
| 视频通话 AppWidget | `dumpsys appwidget` 全量 provider + `dumpsys package com.tencent.mm` 的 APPWIDGET_UPDATE 接收器 | 微信**仅暴露 1 个小组件**：`plugin.appbrand.outerwidget.AppBrandOuterWidget`（小程序桌面组件），**无视频通话 widget**；无相关 disabledComponents |
| 直拨 Intent | 包解析表 MIME `vnd.android.cursor.item/vnd.com.tencent.mm.chatting.voip(.video)` | 全部指向 `plugin.account.ui.ContactsSyncUI`（联系人同步/资料页），**不能直达视频呼叫** |
| URL Scheme | 包解析表 Schemes 段 | 仅 `weixin://` 通用入口（WXCustomSchemeEntryActivity）、`qr`、`pay`、`wechat://recovery-v3`，**无通话类 scheme** |
| 桌面快捷方式 | `dumpsys shortcut` | 无微信视频相关 shortcut |

推论：网传"安卓长按桌面→小工具→微信视频通话"与实测不符（应为 iOS 锁屏组件的混淆或厂商定制锁屏卡片，第三方无法内嵌）。**安卓上触达微信视频只剩 A（无障碍自动）/ B（半自动引导）**；红米真机仍需验证关怀模式布局与 HyperOS 无障碍路径（A/B 的适配基准）。
