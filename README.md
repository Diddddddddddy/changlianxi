# 常联系 · Changlianxi

> 想你了，就见一面。

面向**低识字老人**的极简亲情通讯应用。核心交互：**一屏一位家人大照片，上下滑动换人，听家人本人录音，点照片就联系**。把「找联系人—选对象—发起联系」的多步操作，压缩成一次滑动、一次点击。

> ## 🚧 本项目仍在开发中（Work in Progress）
> 这是一个参赛公益项目的**进行中**快照，尚未发布正式版本。Android 端已完成本地核心交互、模拟通话，并新增**真实蜂窝拨号**（家属预设号码、老人明确点击才拨出）；本地核心与模拟通话已通过模拟器验证，**真实拨号目前仅完成模拟器「交棒系统电话」验证，真机拨通与老人用户测试尚未进行**；微信真实视频接入尚未开始。**公开网页演示与仓库示例仍为纯本地模拟，不含任何真实号码、不会拨出真实电话**；真实拨号只在老人本机、由家属录入号码后才启用。接口、目录与文档都可能随时变化，欢迎观察与建议，但暂不建议用于生产。

## 这个项目做什么

许多老人会刷短视频，却不会读联系人姓名、在微信里寻找聊天对象、记住多步操作；想家人时只能等家人打过来。常联系把「辨认目标—选择对象—发起联系」简化为认照片、听声音、点一下：

- **家属做设置，老人零配置**：家属提前设好照片、本人录音、称呼与拨打方式；老人日常页面没有配置入口。
- **一屏一人**：全屏家人大照片 + 大字号称呼，上下滑动换人；**循环衔接**——末位再下滑回首位、首位再上滑回末位（仅 1 位时停住不循环）。
- **本人声音**：停稳后播放该家人本人录音；系统提示也用对应家人的音色。
- **真实拨号（可选）**：家属为某位家人填入手机号后，老人点照片即可拨出**真实蜂窝电话**（默认一键直拨，可改用零权限的系统拨号盘）；留空则仍是纯本地模拟。呼出后由家人微信视频打回来，也是一种更简洁的「见一面」。
- **失败关闭**：身份不确定就不拨号；每次呼叫都由老人明确点击触发，绝不后台自动拨号／自动接听。
- **诚实状态**：请求发起 ≠ 已拨通 ≠ 已接听，状态机严格区分；模拟通话全程标注「非真实通话」，真实拨号交棒系统电话后绝不假装「已接通」。

## 技术栈

| 端 | 技术 |
|---|---|
| Android | Kotlin 2.2.0 + Jetpack Compose（Material 3）+ VerticalPager；ViewModel/StateFlow；本地 JSON 配置 + 私有媒体文件；`CallGateway` 接缝 + `DemoCallGateway`（纯本地模拟）/ `RealCallGateway`（真实蜂窝拨号，决策由纯逻辑 `RealCallPlanner` 负责） |
| 网站 | 原生 HTML/CSS/ES Modules，无框架无构建；localStorage 演示配置；单实例音频 + 状态机覆盖层 |
| 素材 | AI 生成虚构肖像（WebP）+ edge-tts 合成语音（MP3），按角色匹配年龄/性别音色 |

- Android：`minSdk = 26`（暂定，待目标真机确认）、`compileSdk = targetSdk = 36`；AGP 8.12.0 / Gradle 8.14.3 / Compose BOM 2025.06.00。
- **权限最小化**：合并清单仅 `RECORD_AUDIO`（录音）+ `CALL_PHONE`（真实拨号；老人在家属页选定「一键直拨」时才申请，可改用零权限的系统拨号盘）。电话硬件声明为可选（`telephony required=false`），无 SIM 设备仍可安装并退回演示。**无网络、通讯录、相机、无障碍、位置等权限**；真实拨号仅由老人明确点击触发，绝不后台拨号／自动接听。

## 快速开始

### 网站演示（无需构建）

```bash
cd changlianxi-site/web
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

虚构演示素材已随仓库提供，开箱即可运行。如需重新生成语音，见 `changlianxi-site/scripts/prepare_assets.py`（依赖 `edge-tts`、`Pillow`；原始肖像 PNG 保留在作者本地）。

### Android 应用

```bash
cd changlianxi
# 配置 JDK 17 与 Android SDK（local.properties 指向本机 SDK，已被 .gitignore 排除）
./gradlew :app:assembleDebug        # 产出 app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest    # 单元测试（74 项）
./gradlew :app:lintDebug            # 静态检查
```

> 作者本地环境：JDK 17 来自 conda 环境，SDK 与 Gradle 缓存放在独立磁盘；这些为本机路径，克隆后请按自己的环境配置 `local.properties`。

## 隐私与安全

这是一个需要老人信任的公益应用，隐私优先：

- **公开仓库与演示不含任何真实家属照片、录音或手机号**。演示素材全部为 AI 生成的虚构人物与合成语音。
- 真实产品中，家人照片与录音仅保存在老人手机**本地私有目录**，默认不上云；**家人相片与语音不提交 Git 仓库**（见开发 SPEC §3.3）。
- **手机号同样仅存本机**：家属录入的号码绑定联系人、存于本地私有配置，不上传、不进日志、不进公开仓库与演示；Android 系统日志也会自动脱敏号码。公开演示只用虚构号码且保持模拟。
- 不读取聊天内容、不截图上传、不扫描全量通讯录、不记录联系人隐私数据。
- **失败关闭**：身份不确定不拨号；不绕过系统权限弹窗、不偷偷启用无障碍、不隐藏退出方式。
- 日志只记录必要的非隐私状态。
